# Source and distribution boundaries

Application modules and reference rules were selectively adapted from the user's private `K1rsam/director-web` repository at the commit recorded in `MIGRATED_SOURCE.json`. Original creative candidates retain their exact bytes and provenance in `SOURCE_INDEX.json` and `rules/stage3/manifest.json`.

No repository-wide license was found in the pinned source tree. This internal private migration must not be interpreted as permission to publish or sublicense that repository or its creative files. Existing source notices are preserved. Dependency licenses and native-binary redistribution/signing remain release gates.

The two included Jimeng CLI help-text files are recorded interface fixtures required by inherited offline parser tests. They are not bundled CLI executables, current capability claims, proof of free usage, or permission to submit image/video tasks.

The SDK bridge, when installed, uses the separately version-pinned official package and its own lockfile. It is kept out of the React browser bundle. See its dependency records for the applicable upstream license.
